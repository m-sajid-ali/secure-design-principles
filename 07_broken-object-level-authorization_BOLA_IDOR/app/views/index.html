Module 3 — Broken Object Level Authorization (BOLA / IDOR)

Authentication is done right here (verified JWT). The question is different: once you're logged in, can you touch objects that aren't yours?

❌ Vulnerable

Fetch by ID only

Log in as alice, then read and cancel Bob's orders just by changing the ID in the URL.

 ✅ Secure

Scoped to the owner

Every query is filtered by the authenticated owner, so other users' orders simply don't exist.

Accounts: alice / S3cret-Alice!, bob / Bob-Pass-123. Orders 1001,1003 = alice · 1002,1004 = bob · 1005 = admin.
