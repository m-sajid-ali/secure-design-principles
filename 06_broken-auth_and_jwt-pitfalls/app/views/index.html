Module 2 — Broken Authentication & JWT

One attacker goal — read others' data / become admin — against five escalating defenses. Watch where each attack dies.

❌ Vulnerable

Levels 1–3

decode() → verify() with a weak secret → a naive/legacy verifier that accepts alg:none.

 ✅ Hardened

Levels 4–5

Strong secret + pinned algorithm + expiry, then a sender-constrained token that a copy can't reuse.
